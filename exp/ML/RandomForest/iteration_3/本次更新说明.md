# 本次更新说明

## 迭代定位

本轮是 RandomForest 的第 3 次迭代，用于大范围同时搜索主要超参数。

## 相比上次的变化

1. 相比 `iteration_2`，从默认参数扩展为大范围随机搜索。
2. 搜索随机森林的树数量、分裂准则、树深度、分裂/叶节点样本数、特征采样、bootstrap、样本采样比例、叶节点上限、最小不纯度下降、代价复杂度剪枝和类别权重。
3. 使用 `RandomizedSearchCV` 而不是完整网格搜索，避免所有候选值笛卡尔组合过大导致运行时间失控。
4. 主选择指标为 5 折 CV 的 `macro F1`，同时观察 `b` 类 recall、`g` 类 F1、accuracy、ROC-AUC 和训练/测试差距。
5. 本轮不搜索 `random_state`、`n_jobs`、`verbose`、`warm_start` 等运行控制参数。

## 搜索设置

本轮使用 `RandomizedSearchCV`，随机采样 `160` 组候选参数，每组做 5 折交叉验证，共约 `800` 次模型拟合。

候选范围：

| 参数 | 候选值 |
| --- | --- |
| `n_estimators` | `100, 200, 300, 500` |
| `criterion` | `gini, entropy, log_loss` |
| `max_depth` | `None, 3, 4, 5, 6, 8, 10, 12, 16` |
| `min_samples_split` | `2, 4, 8, 12, 20` |
| `min_samples_leaf` | `1, 2, 4, 8, 12` |
| `max_features` | `sqrt, log2, None, 0.3, 0.5, 0.7` |
| `bootstrap` | `True, False` |
| `max_samples` | `None, 0.6, 0.8, 1.0`，仅在 `bootstrap=True` 时使用 |
| `max_leaf_nodes` | `None, 8, 16, 32, 64` |
| `min_impurity_decrease` | `0.0, 0.001, 0.005, 0.01` |
| `ccp_alpha` | `0.0, 0.001, 0.005, 0.01` |
| `class_weight` | `None, balanced, balanced_subsample` |

## 最优参数

以 5 折 CV 的 `macro F1` 作为主选择指标，最优组合为：

```text
n_estimators = 300
criterion = log_loss
max_depth = None
min_samples_split = 8
min_samples_leaf = 4
max_features = 0.3
bootstrap = True
max_samples = 1.0
max_leaf_nodes = 16
min_impurity_decrease = 0.0
ccp_alpha = 0.001
class_weight = None
```

网格搜索中的最佳 `macro F1` 为 `0.9397`。

## 当前结论

大范围超参数搜索确实缓解了训练集满分问题：训练集 accuracy 从 `1.0000` 降到约 `0.9786`，说明模型复杂度被控制住了。

但本轮不是全面优于默认随机森林。它在 5 折 CV 的 accuracy 和 F1(g) 上更好，单次 ROC-AUC 也更高；但单次 accuracy、单次 F1(g)、`b` 类 recall，以及重复划分均值都低于默认参数。

因此当前结论是：`iteration_3` 是一个更保守、复杂度更低的随机森林版本，适合作为“控制过拟合”的实验结果；但如果按重复划分稳定性和综合表现选择，`iteration_2` 默认随机森林仍然很有竞争力。
