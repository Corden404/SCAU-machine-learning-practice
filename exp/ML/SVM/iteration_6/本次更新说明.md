# 本次更新说明

## 迭代定位

本轮固定第五次迭代确认的最佳 SVM 模型，只调整最终分类阈值。

## 相比上次的变化

1. 保留 `StandardScaler + RBF SVC(C=3.0, gamma=0.03, class_weight='balanced')`。
2. 不再搜索 `kernel`、`C`、`gamma` 或 `class_weight`。
3. 基于训练数据内部 5 折 out-of-fold `decision_function` 分数搜索阈值。
4. 主目标优先最大化 macro F1。
5. 同时观察 `b` 类 recall、`g` 类 F1 和 accuracy。

## 防止数据泄漏

本轮不在测试集上直接寻找阈值。每次模型 `fit` 时，只用当前训练数据内部的 5 折 out-of-fold 分数选择阈值，然后再把该阈值用于测试集、CV 验证折或多随机种子测试集。

## 预期意义

如果阈值调整有效，说明当前 SVM 的排序能力可以通过改变决策边界换成更好的类别平衡；如果无效，则说明默认阈值已经足够接近当前模型的最佳分类点。

## 运行结果

本轮固定模型参数为：

1. `kernel='rbf'`
2. `C=3.0`
3. `gamma=0.03`
4. `class_weight='balanced'`

全数据 out-of-fold 参考搜索中，最佳阈值为 `0.0`，与默认阈值一致，macro F1 为 0.9564。

但在单次训练集内部阈值搜索中，选择阈值为 `0.1208`。这会让模型更谨慎地预测 `g` 类，从而提高 `b` 类 recall。

单次测试集结果：

|---|---:|---:|---:|

## 结论

阈值调整不是单方面提升。它明显提高了 `b` 类 recall，并在单次测试集和多随机种子均值上更好；但 5 折 CV 的 accuracy、macro F1 和 `g` 类 F1 低于 iteration_5。

因此 iteration_6 可以作为“更重视 `b` 类召回率和多随机种子表现”的版本。如果最终模型选择以 5 折 CV macro F1 为主，iteration_5 仍更稳；如果更重视少数类识别和多随机种子均值，iteration_6 更值得考虑。
