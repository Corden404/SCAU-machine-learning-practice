# 本次更新说明

## 迭代定位

本轮在 `iteration_3` 的最佳方案上继续改进：固定 `C=3.0`，一次性联动验证 `gamma` 和 `class_weight`。

## 相比上次的变化

1. 保留 `StandardScaler + RBF SVC`。
2. 固定第三次迭代得到的最佳 `C=3.0`，不重新搜索 `C`。
3. 搜索 `gamma`：`scale`, `0.01`, `0.03`, `0.1`, `0.3`, `1.0`。
4. 同时比较 `class_weight=None` 与 `class_weight='balanced'`。
5. 使用 5 折交叉验证的 macro F1 选择最佳组合，同时观察 accuracy、`b` 类 recall、ROC-AUC 和多随机种子稳定性。

## 关于是否冲突

`gamma` 和 `class_weight` 不会在代码或模型定义上冲突。`gamma` 控制 RBF 核的局部影响范围，`class_weight` 调整类别错分惩罚，二者作用位置不同。

但它们会间接共同影响决策边界，因此本轮采用小网格联动验证，而不是分别单独判断。

## 运行结果

本轮最佳组合为：

1. `C=3.0`
2. `kernel='rbf'`
3. `gamma=0.03`
4. `class_weight='balanced'`

主要结果如下：

| 指标 | iteration_3 | iteration_4 | 变化 |
|---|---:|---:|---:|
| 单次 accuracy | 0.9577 | 0.9577 | +0.0000 |
| 单次 F1 | 0.9677 | 0.9677 | +0.0000 |
| 单次 ROC-AUC | 0.9748 | 0.9765 | +0.0017 |
| CV accuracy | 0.9515 | 0.9600 | +0.0085 |
| CV F1 | 0.9629 | 0.9690 | +0.0061 |
| CV ROC-AUC | 0.9790 | 0.9822 | +0.0032 |
| 多种子 accuracy | 0.9549 | 0.9521 | -0.0028 |
| 多种子 F1 | 0.9663 | 0.9639 | -0.0023 |
| 多种子 ROC-AUC | 0.9875 | 0.9873 | -0.0002 |

## 结论

本轮在 5 折 CV 上有明显收益，尤其是 macro F1、accuracy 和 `b` 类 recall 均提高；单次测试集预测类别不变，ROC-AUC 小幅提高。

但多随机种子均值略低于 iteration_3，只是波动更小。因此 iteration_4 可以作为以 CV macro F1 和类别均衡为主时的新 baseline；如果后续特别强调多随机种子均值，仍需要保留 iteration_3 作为对照。
