# SVM 记录

## 1. 当前实验概况

SVM 用于观察 Ionosphere 数据在间隔最大化分类器上的表现。当前已经完成八轮迭代：

1. `iteration_1`：默认参数 SVM，直接使用原始 34 个特征。
2. `iteration_2`：在 SVM 前加入 `StandardScaler`，并增加交叉验证和多随机种子评估。
3. `iteration_3`：沿用 `StandardScaler + RBF SVC`，只搜索 `C`，固定 `gamma='scale'`。
4. `iteration_4`：固定 `C=3.0`，联动搜索 `gamma` 和 `class_weight`。
5. `iteration_5`：跳出贪心路线，重新搜索 `linear/rbf/poly` 核及主要超参数，验证多项式核是否更优。
6. `iteration_6`：固定最佳 RBF SVM 参数，调整决策阈值，优先最大化 macro F1。
7. `iteration_7`：30 种子扩大稳定性验证，推翻 iter_6 的 5 种子结论。
8. `iteration_8`：测试 RobustScaler + PCA 预处理，验证离群值处理是否改善 SVM。

SVM iter_5（StandardScaler + RBF SVC, C=3.0, gamma=0.03, balanced）是当前最佳单模型。

## 5. iteration_4 调 gamma 与 class_weight 后结果

本轮按用户要求一次性加入 `gamma` 和 `class_weight` 的搜索，但仍保持小网格：固定第三轮得到的 `C=3.0`，只搜索 RBF 核的 `gamma` 与类别权重。

`gamma` 和 `class_weight` 不会在代码或模型定义上冲突。`gamma` 控制 RBF 核的局部影响范围，`class_weight` 调整不同类别的错分惩罚，二者作用位置不同。但它们都会影响最终决策边界，因此本轮采用联动小网格验证，而不是分别孤立判断。

| kernel | `rbf` |
| gamma | `scale`, `0.01`, `0.03`, `0.1`, `0.3`, `1.0` |
| class_weight | `None`, `balanced` |

网格搜索结果显示，最佳组合为：

|---|---|
| C | `3.0` |
| kernel | `rbf` |

| class_weight | `balanced` |

| scale | balanced | 0.9532 | 0.9572 | 0.9206 | 0.9824 | 0.9791 |

如果以 5 折 CV macro F1 和类别均衡为主，iteration_4 可以接受为新的 SVM baseline；如果以多随机种子均值为主，iteration_3 仍需要作为强对照保留。

## 6. iteration_5 全量搜索与多项式核结果

本轮是一次探索性对照实验：不再坚持前面的贪心路线，而是重新搜索 SVM 的主要超参数，并加入多项式核 `poly`。这样做的目的不是保证指标一定提高，而是验证“更复杂的核函数和更大的搜索空间是否能超过当前 RBF 方案”。

搜索范围如下：

| 参数 | 候选值 |
|---|---|
| kernel | `linear`, `rbf`, `poly` |
| C | `0.1`, `0.3`, `1.0`, `3.0`, `10.0`, `30.0` |
| gamma | `scale`, `0.01`, `0.03`, `0.1`, `0.3`, `1.0` |
| class_weight | `None`, `balanced` |
| poly degree | `2`, `3`, `4` |
| poly coef0 | `0.0`, `0.5`, `1.0` |

本轮共搜索 732 个候选组合。最佳组合仍然是 iteration_4 中已经得到的 RBF 方案：

| 参数 | 最佳值 |
|---|---|
| kernel | `rbf` |
| C | `3.0` |
| gamma | `0.03` |
| class_weight | `balanced` |

各核函数的最佳结果如下：

| kernel | C | gamma | degree | coef0 | class_weight | CV macro F1 | CV accuracy | CV `b` recall | train macro F1 |
|---|---:|---|---:|---:|---|---:|---:|---:|---:|
| rbf | 3.0 | 0.03 | - | - | balanced | 0.9563 | 0.9600 | 0.9283 | 0.9791 |
| poly | 0.1 | 0.3 | 2 | 0.0 | balanced | 0.9227 | 0.9316 | 0.8335 | 0.9821 |
| linear | 1.0 | - | - | - | None | 0.8857 | 0.9002 | 0.7766 | 0.9427 |

第五轮最终选择的模型与第四轮完全相同，因此单次测试、5 折 CV 和多随机种子汇总指标也与 iteration_4 一致。

这个结果说明：全量搜索没有推翻第四轮结论。多项式核的最佳 CV macro F1 只有 0.9227，明显低于 RBF 的 0.9563；linear 核更低，说明 Ionosphere 数据确实需要非线性边界，但当前更适合 RBF 核，而不是多项式核。

多项式核的一个典型问题也在这里体现出来：它的 train macro F1 为 0.9821，高于 RBF 的 0.9791，但 CV macro F1 明显更低。这说明 poly 核并不是因为拟合能力不够，而是泛化效果不好。后续不建议继续沿着 poly 的 `degree/coef0/gamma/C` 扩大搜索。

因此 iteration_5 是一个有价值的负结果：它没有提高最终指标，但证明了 iteration_4 的小网格 RBF 方案没有错过明显更优的多项式核组合。

## 7. iteration_6 阈值调整结果

本轮固定模型本身，不再调整核函数或超参数，只调整 `decision_function` 的分类阈值。固定模型为：

| 参数 | 值 |
|---|---|
| pipeline | `StandardScaler + RBF SVC` |
| C | `3.0` |
| gamma | `0.03` |
| class_weight | `balanced` |

阈值选择方式：每次模型 `fit` 时，仅在当前训练数据内部做 5 折 out-of-fold 预测，基于这些训练内 OOF 决策分数搜索阈值，主目标最大化 macro F1。这样不直接用测试集调阈值。

全数据 OOF 参考搜索中，最佳阈值为 `0.0`，与默认 SVM 阈值一致：

| 阈值 | macro F1 | accuracy | `b` recall | `g` F1 |
|---:|---:|---:|---:|---:|
| 0.0 | 0.9564 | 0.9601 | 0.9286 | 0.9692 |

但在单次训练集内部搜索中，最佳阈值为 `0.1208`。正阈值会让模型更谨慎地预测 `g` 类，也就是需要更强的 `g` 类决策分数才判为 `g`，因此会提高 `b` 类 recall，但可能牺牲一部分 `g` 类 recall/F1。

单次测试集结果：

| 指标 | iteration_5 | iteration_6 | 变化 |
|---|---:|---:|---:|
| accuracy | 0.9577 | 0.9577 | +0.0000 |
| macro F1 | 0.9533 | 0.9541 | +0.0008 |
| `b` recall | 0.9200 | 0.9600 | +0.0400 |
| `g` F1 | 0.9677 | 0.9670 | -0.0007 |
| ROC-AUC | 0.9765 | 0.9765 | +0.0000 |

5 折交叉验证结果：

| 指标 | iteration_5 | iteration_6 | 变化 |
|---|---:|---:|---:|
| accuracy | 0.9600 | 0.9543 | -0.0057 |
| macro F1 | 0.9563 | 0.9508 | -0.0055 |
| `b` recall | 0.9283 | 0.9363 | +0.0080 |
| `g` F1 | 0.9690 | 0.9638 | -0.0052 |
| ROC-AUC | 0.9822 | 0.9822 | +0.0000 |

5 个随机种子重复划分结果：

| 指标 | iteration_5 | iteration_6 | 变化 |
|---|---:|---:|---:|
| accuracy | 0.9521 | 0.9662 | +0.0141 |
| `g` F1 | 0.9639 | 0.9739 | +0.0100 |
| ROC-AUC | 0.9873 | 0.9873 | +0.0000 |
| macro F1 | 未记录 | 0.9629 | - |
| `b` recall | 未记录 | 0.9520 | - |

第六轮的结果不是单方面提升，而是一个取舍：阈值调整明显提高了 `b` 类 recall，并且在单次测试集和多随机种子均值上更好；但 5 折 CV 的 accuracy、macro F1 和 `g` 类 F1 低于 iteration_5。

因此 iteration_6 可以作为“更重视少数类 `b` 召回率和多随机种子表现”的版本。如果最终选择标准是 5 折 CV macro F1，iteration_5 仍更合适；如果更重视 `b` 类识别和多随机种子均值，iteration_6 值得作为最终候选。

## 8. 与逻辑回归最佳 baseline 对比

与 `LogisticRegression/iteration_4` 对比：

| 模型 | 单次 accuracy | 单次 F1 | 单次 ROC-AUC | CV accuracy | CV F1 | 多种子 accuracy | 多种子 F1 |
|---|---:|---:|---:|---:|---:|---:|---:|
| LogisticRegression iteration_4 | 0.9577 | 0.9684 | 0.9922 | 0.9458 | 0.9589 | 0.9408 | 0.9559 |
| SVM iteration_1 | 0.9577 | 0.9677 | 0.9704 | 未记录 | 未记录 | 未记录 | 未记录 |
| SVM iteration_2 | 0.9577 | 0.9677 | 0.9713 | 0.9401 | 0.9548 | 0.9465 | 0.9602 |
| SVM iteration_3 | 0.9577 | 0.9677 | 0.9748 | 0.9515 | 0.9629 | 0.9549 | 0.9663 |
| SVM iteration_4 | 0.9577 | 0.9677 | 0.9765 | 0.9600 | 0.9690 | 0.9521 | 0.9639 |
| SVM iteration_5 | 0.9577 | 0.9677 | 0.9765 | 0.9600 | 0.9690 | 0.9521 | 0.9639 |
| SVM iteration_6 | 0.9577 | 0.9670 | 0.9765 | 0.9543 | 0.9638 | 0.9662 | 0.9739 |

从单次测试集看，SVM iteration_4/5/6 与逻辑回归最佳版本的 accuracy 完全相同。以 `g` 为正类的 F1 上，iteration_4/5 只低 0.0007，iteration_6 低 0.0014；但从 macro F1 和 `b` 类 recall 看，iteration_6 更均衡。

从 5 折交叉验证看，SVM iteration_4/5 仍是最强版本：accuracy 高于逻辑回归 0.0143，F1 高 0.0102。iteration_6 的 CV 均值也高于逻辑回归，但不如 iteration_4/5。

从多随机种子划分看，SVM iteration_6 当前最好：accuracy 为 0.9662，比逻辑回归 iteration_4 高 0.0254；F1 为 0.9739，比逻辑回归高 0.0180。

另外，SVM iteration_4/5/6 的多随机种子 ROC-AUC 均约为 0.9873，高于逻辑回归 iteration_4 的 0.9755；5 折 CV ROC-AUC 也高于逻辑回归。说明 SVM 的排序能力仍然很强。

需要注意的是，当前 `test_f1` 是以 `g` 为正类的 F1，不是 macro F1。单次测试集中，SVM iteration_6 的 macro F1 为 0.9541，逻辑回归 iteration_4 的 macro F1 为 0.9523，SVM 反而略高。原因是 SVM iteration_6 对少数类 `b` 的 recall 为 0.9600，高于逻辑回归 iteration_4 的 0.8800；而逻辑回归对 `g` 类 recall 达到 1.0000，所以 positive-class F1 略高。

从过拟合角度看，SVM iteration_4 仍比逻辑回归二阶升维更克制。5 折 CV 中，SVM 的 train accuracy/test accuracy 差距约为 0.0207，逻辑回归 iteration_4 约为 0.0485；多随机种子中，SVM 差距约为 0.0272，逻辑回归约为 0.0513。逻辑回归二阶升维后训练分数接近满分，虽然测试结果很好，但复杂度压力明显更大。

SVM iteration_4 的多随机种子 accuracy 标准差为 0.0214，已经接近逻辑回归 iteration_4 的 0.0209；iteration_6 进一步降到 0.0126。也就是说，阈值调整不仅提高了多随机种子均值，也让重复划分结果更稳定。

逻辑回归需要通过二阶多项式升维才能达到当前最佳表现，而 SVM 默认 RBF 核本身就可以表达非线性边界。这说明 SVM 很可能适合 Ionosphere 这种“小样本 + 相对高维”的数据。

## 9. 当前结论

SVM 前六轮结果说明：

1. 默认 RBF SVM 已经是一个很强的 baseline。
2. 标准化后没有改变单次分类结果，但流程上更合理，应作为后续调参的固定步骤。
3. SVM 对 `b` 类和 `g` 类的表现比较均衡，`b` 类 recall 为 0.9200，高于逻辑回归 iteration_2 的 0.8400，也高于逻辑回归 iteration_4 的 0.8800。
4. 只调整 `C` 是有效的贪心改进。`C=3.0` 相比默认 `C=1.0` 提高了 CV accuracy、CV F1、多随机种子 accuracy 和多随机种子 F1。
5. 当前 SVM iteration_4 在 CV 均值上是最好的版本，CV accuracy 为 0.9600，CV F1 为 0.9690。
6. iteration_6 的多随机种子均值最高，但 5 折 CV 不如 iteration_4/5，因此最终报告中应同时说明二者取舍：iteration_4/5 更重视 CV macro F1，iteration_6 更重视 `b` 类 recall 和多随机种子表现。
7. 全量搜索和多项式核没有超过 iteration_4。poly 核最优 CV macro F1 明显低于 RBF，说明不应继续沿着多项式核复杂化方向推进。
8. 阈值调整提高了 `b` 类 recall 和多随机种子均值，但降低了 5 折 CV macro F1，因此它是一个有取舍的版本。
9. 继续增大 `C` 或 `gamma` 会让训练分数接近满分，容易过拟合，因此也不应再沿着提高边界复杂度的方向推进。

## 10. 后续迭代思路

后续不采用“一次性搜索所有可能组合”的方式，而是采用贪心迭代：先试一个明确改动，有效果就保留；再在它的基础上试下一个改动。只有参数之间存在明显相互影响时，才做小范围联动复核。

当前如果以 5 折 CV macro F1 作为主标准，SVM 主版本仍定为 `iteration_4/iteration_5` 对应的同一组参数：`StandardScaler + RBF SVC(C=3.0, gamma=0.03, class_weight='balanced')`。如果更强调 `b` 类 recall 和多随机种子均值，则 `iteration_6` 是更强候选。

每轮判断规则如下：

1. 主指标看 macro F1，避免只照顾多数类 `g`。
2. 辅助看 accuracy、以 `g` 为正类的 F1、ROC-AUC 和 `b` 类 recall。
3. 如果均值提升但训练集和测试集差距明显扩大，认为有过拟合风险，不直接接受。
4. 如果提升很小但波动变大，优先保留更简单、更稳定的上一轮方案。
5. 如果新改动没有收益，后续迭代回到上一轮最优方案继续。

### 后续建议：扩大稳定性验证

现在主要矛盾不再是模型复杂度，而是不同评估方式下的取舍：iteration_4/5 的 5 折 CV 最好，iteration_6 的多随机种子均值最好。下一步更适合把 iteration_4/5 和 iteration_6 放到更多随机种子上重复验证，例如 20 或 30 个 seed，再决定最终采用哪一个版本。

### 已验证但不优先继续的方向

1. 已完成 `linear/rbf/poly` 一次性大网格搜索，最佳结果仍是 RBF。
2. poly 核最优结果明显低于 RBF，后续不建议继续扩大 poly 搜索。
3. 暂不加显式 `PolynomialFeatures`，因为 SVM 的 RBF 核已经提供非线性表达能力，而显式升维可能进一步增加过拟合风险。

## 11. 预期观察点

后续每轮重点不只看单次测试集 accuracy，而应重点观察：

1. 5 折 CV mean 是否继续保持超过逻辑回归 iteration_4 的 0.9458 accuracy 和 0.9589 positive-class F1。
2. 多随机种子 mean 是否继续稳定超过逻辑回归 iteration_4 的 0.9408 accuracy 和 0.9559 F1。
3. macro F1 是否保持或超过当前 SVM 单次测试集的 0.9533，避免只优化 `g` 类。
4. `b` 类 recall 是否能保持在 0.9200 或更高。
5. 训练集和测试集差距是否扩大，如果差距明显扩大，说明模型复杂度过高。
6. 多随机种子标准差是否下降。当前 SVM 均值不错，但波动比逻辑回归大，后续迭代不只追求最高均值，也要看稳定性。

## 13. iteration_8 RobustScaler + PCA 预处理

本轮根据数据预分析结果测试两种预处理改进：
- **RobustScaler** 替代 StandardScaler（针对 47% IQR 离群值）
- **PCA 降维** 保留 90%/95%/99% 方差

SVC 参数沿用 iter_5 最优配置，GridSearchCV 选择最佳预处理方案（36 组候选）。

### 13.1 搜索结果

| 预处理方案 | CV macro F1 | 最佳 C | 最佳 gamma |
| --- | ---: | ---: | ---: |
| RobustScaler only | **0.9530** | 3.0 | 0.03 |
| RobustScaler + PCA(0.99) | 0.9500 | 3.0 | 0.03 |
| RobustScaler + PCA(0.95) | ~0.948 | — | — |
| RobustScaler + PCA(0.90) | ~0.942 | — | — |

RobustScaler only 胜出。PCA 降维对 SVM 有害，方差保留越少越差。

### 13.2 与 iter_5 (StandardScaler) 对比

| 指标 | iter_5 StandardScaler | iter_8 RobustScaler | Δ |
| --- | ---: | ---: | ---: |
| CV accuracy | 0.9600 | 0.9573 | -0.0027 |
| CV F1(g) | 0.9690 | 0.9672 | -0.0018 |
| CV ROC-AUC | 0.9822 | 0.9839 | +0.0017 |
| Repeated accuracy | 0.9521 | 0.9549 | +0.0028 |
| Repeated F1(g) | 0.9639 | 0.9663 | +0.0024 |
| Repeated ROC-AUC | 0.9873 | 0.9861 | -0.0012 |

### 13.3 结论

1. **RobustScaler 未带来实质提升。** 所有差异在 ±0.003 内，属于噪声范围。SVM RBF 核对离群值有足够鲁棒性，StandardScaler 已是最优。
2. **PCA 降维对 SVM 有害。** 34 个特征的有效信号分布均匀，任何降维都丢失信息。
3. **数据预处理改进空间已穷尽。** iter_5 保持最佳单模型版本。
4. **此结果也反向验证了 StandardScaler + RBF SVC 选择的正确性。**

## 12. iteration_7 30 种子扩大稳定性验证结果

本轮不再调整模型参数，只对 iteration_4/5 模型（默认阈值）和 iteration_6 模型（阈值调优）做 30 个随机种子（0-29）的扩大稳定性验证，每个 seed 上两个模型使用完全相同的 train/test 划分。

### 12.1 30 种子 repeated split 汇总

| 指标 | iter_4/5 mean | iter_4/5 std | iter_6 mean | iter_6 std | Δ (i6-i45) |
|---|---:|---:|---:|---:|---:|
| accuracy | 0.9540 | 0.0261 | 0.9531 | 0.0257 | -0.0009 |
| macro_f1 | 0.9488 | 0.0295 | 0.9486 | 0.0282 | -0.0002 |
| b_recall | 0.9173 | 0.0672 | 0.9400 | 0.0601 | **+0.0227** |
| g_f1 | 0.9650 | 0.0196 | 0.9636 | 0.0201 | -0.0014 |
| roc_auc | 0.9863 | 0.0113 | 0.9863 | 0.0113 | 0.0000 |

### 12.2 iter_6 各 seed 上对 iter_4/5 的胜率

| 指标 | iter_6 赢 | iter_6 输 | 平 |
|---|---:|---:|---:|
| test macro_f1 | 8 | 9 | 13 |
| test b_recall | 11 | 0 | 19 |
| test g_f1 | 7 | 10 | 13 |

"平"（ties）的原因是在 19 个 seed 上，阈值搜索得到的最佳阈值接近 0.0，此时 iter_6 等价于 iter_4/5。

### 12.3 5 折 CV（本轮复跑，与历史一致）

| 指标 | iter_4/5 CV | iter_6 CV |
|---|---:|---:|
| accuracy | 0.9600 | 0.9543 |
| macro_f1 | 0.9563 | 0.9508 |
| b_recall | 0.9283 | 0.9363 |
| g_f1 | 0.9690 | 0.9638 |
| roc_auc | 0.9822 | 0.9822 |

### 12.4 关键发现

**1. 5 种子结果严重高估了 iter_6 的优势。** iteration_6 的 5 种子 repeated F1(g) 为 0.9739，30 种子降到 0.9636。种子 0-4 刚好是阈值调整比较受益的一组划分，扩大到 30 种子后均值大幅回落。

**2. iter_6 在 30 种子上不赢 iter_4/5。** test macro F1 胜率只有 8/30（26.7%），test g_f1 胜率只有 7/30（23.3%）。换句话说，在约 73% 的随机划分上，默认阈值至少不逊于阈值调优。

**3. iter_6 的唯一稳定优势是 b_recall。** 30 种子均值 +0.0227，但这是在牺牲 g_recall（-0.0138）和 g_f1（-0.0014）的前提下得到的。当阈值不是 0.0 时（11/30 的 seed），b_recall 会提升，但同时 g_recall 下降。

**4. 两个模型的标准差几乎一样。** iter_6 并没有让跨 seed 结果更稳定，acc std 都是 ~0.026，macro_f1 std 都是 ~0.029。阈值调整不会改善稳定性，只是把均值在 g 类和 b 类之间重新分配。

**5. 训练/测试差距没有变化。** 两个模型的 train-test gap 基本相同，iter_4/5 为 macro_f1 gap 0.0315，iter_6 为 0.0309。阈值调整没有增加过拟合风险，但也没有降低。

### 12.5 本轮结论

30 种子验证推翻了 iteration_6 "多随机种子均值更好" 的 5 种子结论：

- **iter_4/5 是唯一应该推荐的最终模型。** 它在 73% 的随机划分上 macro_f1 不输 iter_6，并且在 5 折 CV 上全面领先（macro_f1 +0.0055）。
- **iter_6 的阈值调整只在少数 seed 上有效。** 在 19/30 的 seed 上，内部 OOF 阈值搜索找到的最佳阈值接近 0.0，与默认阈值无异。
- **iter_6 从"强候选"降级为"b 类优先的补充说明"。** 如果报告中需要讨论"如何进一步提高少数类召回"，可以用 iter_6 的阈值调整作为实验佐证，但不应作为推荐最终模型。

### 12.6 更新后的最终建议

最终推荐模型确定为 **SVM iteration_4/5：StandardScaler + RBF SVC(C=3.0, gamma=0.03, class_weight='balanced')**，使用默认阈值 0.0。

这与之前基于 5 折 CV macro F1 的结论一致，现在得到了 30 种子 repeated split 的独立验证支持。
