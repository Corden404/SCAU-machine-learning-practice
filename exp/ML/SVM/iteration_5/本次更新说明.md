# 本次更新说明

## 迭代定位

本轮是一次跳出贪心路线的探索实验：重新搜索 SVM 的主要超参数，并加入多项式核 `poly`。

## 相比上次的变化

1. 不再固定 `C=3.0`，重新搜索 `C`。
2. 同时比较 `linear`、`rbf` 和 `poly` 核函数。
3. 对 `rbf` 和 `poly` 搜索 `gamma`。
4. 对 `poly` 额外搜索 `degree` 和 `coef0`。
5. 同时搜索 `class_weight=None` 与 `class_weight='balanced'`。
6. 仍使用 5 折交叉验证 macro F1 作为主选择指标。

## 搜索范围

| 参数 | 候选值 |
|---|---|
| kernel | `linear`, `rbf`, `poly` |
| C | `0.1`, `0.3`, `1.0`, `3.0`, `10.0`, `30.0` |
| gamma | `scale`, `0.01`, `0.03`, `0.1`, `0.3`, `1.0` |
| class_weight | `None`, `balanced` |
| poly degree | `2`, `3`, `4` |
| poly coef0 | `0.0`, `0.5`, `1.0` |

## 预期意义

如果结果更好，说明前面的贪心路线可能错过了更优组合；如果结果变差或只是持平，也要保留记录，用于说明更复杂的多项式核和全量搜索并不一定带来泛化收益。

## 运行结果

本轮共搜索 732 个候选组合。最佳组合仍然是第四次迭代已经得到的 RBF 核方案：

1. `kernel='rbf'`
2. `C=3.0`
3. `gamma=0.03`
4. `class_weight='balanced'`

各核函数的最佳结果如下：

| kernel | C | gamma | degree | coef0 | class_weight | CV macro F1 | CV accuracy | CV `b` recall |
|---|---:|---|---:|---:|---|---:|---:|---:|
| rbf | 3.0 | 0.03 | - | - | balanced | 0.9563 | 0.9600 | 0.9283 |
| poly | 0.1 | 0.3 | 2 | 0.0 | balanced | 0.9227 | 0.9316 | 0.8335 |
| linear | 1.0 | - | - | - | None | 0.8857 | 0.9002 | 0.7766 |

第五次迭代最终模型与第四次迭代相同，因此单次测试、CV 和多随机种子结果也与 iteration_4 一致。

## 结论

全量搜索没有找到超过 iteration_4 的方案。多项式核最优结果明显低于 RBF 核，说明继续沿着 poly 核增加复杂度不是当前数据集上的优先方向。

本轮虽然没有提升指标，但它是有价值的对照实验：它证明第四次迭代的小网格搜索没有错过明显更优的多项式核组合，也为后续不继续尝试复杂核函数提供依据。
