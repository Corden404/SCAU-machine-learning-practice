# 本次更新说明

## 迭代定位

本轮在 `iteration_3` 的最佳 `ccp_alpha` 剪枝树基础上，继续搜索 `max_depth` 和 `min_samples_leaf`。

## 相比上次的变化

1. 固定 `iteration_3` 得到的 `ccp_alpha=0.00852480852480852`。
2. 搜索 `max_depth`：`3`, `4`, `5`, `6`, `7`, `8`, `None`。
3. 搜索 `min_samples_leaf`：`1`, `2`, `3`, `5`, `8`, `10`。
4. 使用 5 折交叉验证的 macro F1 选择最佳组合。
5. 同时观察 accuracy、`b` 类 recall、`g` 类 F1、ROC-AUC、树深度和叶子数。

## 设计说明

`max_depth` 和 `min_samples_leaf` 都是树复杂度控制参数，会相互影响，因此本轮联动搜索二者。`ccp_alpha` 已经在上一轮确定，本轮先固定它，避免把搜索空间一次性扩大过多。

## 运行结果

本轮最佳参数为：

```text
ccp_alpha = 0.00852480852480852
max_depth = 8
min_samples_leaf = 1
```

最佳树结构：

| 指标 | 值 |
|---|---:|
| tree depth | 7 |
| leaf count | 13 |

虽然最佳 `max_depth=8`，但实际树深仍为 7，说明上一轮的 `ccp_alpha` 仍然是主要约束。

单次测试集结果：

|---|---:|---:|---:|
| accuracy | 0.9155 | 0.9296 | +0.0141 |

| `b` recall | 0.8800 | 0.9200 | +0.0400 |

## 结论

本轮是小幅有效改进。`max_depth=8, min_samples_leaf=1` 在 CV macro F1 上略高于 iteration_3，并改善了单次测试集表现和 ROC-AUC。

但多随机种子 accuracy 基本不变，F1 略低，说明继续微调单棵树的收益已经很有限。当前可以把 iteration_4 作为单棵决策树的最佳分类版本，但下一步更建议转向随机森林。
