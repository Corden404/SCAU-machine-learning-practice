# 本次更新说明

## 迭代定位

本轮固定 `iteration_3` 的 `ccp_alpha=0.00852480852480852`，仅比较三种分裂准则（criterion）：`gini`、`entropy`、`log_loss`。

## 相比上次的变化

1. 固定 `ccp_alpha=0.00852480852480852`。
2. 搜索 `criterion`：`gini`、`entropy`、`log_loss`。
3. 使用 5 折交叉验证的 macro F1 选择最佳准则。
4. 不再搜索 `max_depth` 和 `min_samples_leaf`，保持默认值。

## 设计说明

前四轮都使用默认 `criterion='gini'`。记录中提到可以观察不同准则的表现。`entropy` 和 `log_loss` 基于信息熵，对概率分布的惩罚比 Gini 更平滑，理论上可能在小样本不平衡数据上有不同表现。

本轮只换准则、不改 ccp_alpha，目的是隔离准则的影响。需要注意 `ccp_alpha=0.00852` 是在 gini 下优化的，对 entropy/log_loss 可能不是最佳剪枝强度。

## 结论

本轮表明：**在相同 ccp_alpha 下，entropy/log_loss 比 gini 更容易过拟合**，且在所有测试指标上均不如 iteration_4。

原因很清楚：`ccp_alpha=0.00852` 是在 gini 下通过 CV 选择的剪枝强度。entropy 树天生需要更强的剪枝才能达到相同复杂度控制——同样 ccp_alpha 下 entropy 树深度为 8、叶子数为 21（gini 为 7 和 13），训练集从 0.9536 反弹到 1.0000。

如果要公平比较准则，应该为每个准则分别搜索最佳 ccp_alpha。但考虑到：
1. iteration_4 的 gini 树已经是经过四轮优化的强 baseline
2. 重新为 entropy 搜索 ccp_alpha 只是重复 iteration_3 的工作
3. 预期收益有限（单棵树天花板已接近）

**不建议继续在单棵决策树上迭代。** 将 iteration_4 保持为单棵决策树的最终 baseline，后续应转向集成模型（随机森林/AdaBoost）或进入跨模型对比阶段。
