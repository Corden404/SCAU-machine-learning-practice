# 本次更新说明

## 迭代定位

本轮是在默认决策树过拟合、第二轮手动限制复杂度后，尝试更系统的后剪枝方法：代价复杂度剪枝 `ccp_alpha`。

## 相比上次的变化

1. 不再手动固定 `max_depth=4` 和 `min_samples_leaf=5`。
2. 使用完整决策树生成 `cost_complexity_pruning_path`，得到候选 `ccp_alpha`。
3. 只搜索 `ccp_alpha`，不同时调整 `max_depth`、`min_samples_leaf` 或 `criterion`。
4. 使用 5 折交叉验证的 macro F1 选择最佳 `ccp_alpha`。
5. 同时观察 accuracy、`b` 类 recall、`g` 类 F1、ROC-AUC 和树深度/叶子数。

## 判断标准

如果 `ccp_alpha` 剪枝能提高 CV 或多随机种子表现，并降低训练/测试差距，则接受为新的单棵树 baseline；如果结果不如 iteration_2，则说明手动浅树约束可能更适合当前数据。

## 结论

`ccp_alpha` 剪枝对分类指标是有效的：CV 和多随机种子 accuracy/F1 都高于 iteration_2，说明它比手动固定 `max_depth=4, min_samples_leaf=5` 更适合当前单棵树分类。

但 ROC-AUC 明显下降，说明剪枝后的树虽然 hard prediction 更稳，但叶子概率/排序能力变差。因此本轮可以作为新的分类 baseline，但如果后续特别关注 ROC-AUC，还需要保留 iteration_2 作为对照。
