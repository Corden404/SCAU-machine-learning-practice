# 本次更新说明

## 迭代定位

本轮是 RandomForest 的第 4 次迭代，用于在 `iteration_2` 默认模型和 `iteration_3` 大范围搜索模型之间做局部搜索，并更重视 repeated split 稳定性。

## 相比上次的变化

1. 相比 `iteration_3`，不再继续扩大搜索空间，而是围绕上一轮较有效的复杂度控制参数做局部搜索。
2. 固定 `bootstrap=True`、`class_weight=None`，避免继续引入过多相互影响因素。
3. 搜索 `n_estimators`、`criterion`、`max_features`、`max_leaf_nodes`、`min_samples_leaf`、`min_samples_split`、`ccp_alpha`、`max_samples`。
4. 先用 5 折 CV 选出前 `24` 个候选，再用多随机种子 repeated split 复评。
5. 最终选择不只看 CV，而是优先看 repeated split 的 `macro F1`，同时观察 accuracy、`b` 类 recall、`g` 类 F1 和 ROC-AUC。

## 搜索设置

第一阶段使用 `RandomizedSearchCV`，随机采样 `220` 组候选参数，每组做 5 折交叉验证。第二阶段取 CV 排名前 `24` 的候选模型，用 `0, 1, 2, 3, 4` 五个随机种子做 repeated split 复评，并按 repeated split 的 `macro F1` 均值选择最终模型。

候选范围：

| 参数 | 候选值 |
| --- | --- |
| `n_estimators` | `100, 200, 300` |
| `criterion` | `gini, entropy, log_loss` |
| `max_features` | `sqrt, 0.3, 0.5` |
| `max_leaf_nodes` | `None, 16, 32` |
| `min_samples_leaf` | `1, 2, 4` |
| `min_samples_split` | `2, 4, 8` |
| `ccp_alpha` | `0.0, 0.001` |
| `max_samples` | `None, 0.8, 1.0` |

固定设置：

```text
bootstrap = True
class_weight = None
```

## 最优参数

CV 阶段的最优参数为：

```text
n_estimators = 200
criterion = entropy
max_features = 0.5
max_leaf_nodes = 32
min_samples_leaf = 1
min_samples_split = 8
ccp_alpha = 0.001
max_samples = 1.0
```

CV 最佳 `macro F1` 为 `0.9460`。

经过 repeated split 复评后，最终选择参数为：

```text
n_estimators = 100
criterion = entropy
max_features = 0.5
max_leaf_nodes = 16
min_samples_leaf = 1
min_samples_split = 2
ccp_alpha = 0.0
max_samples = 1.0
```

该候选在 repeated split 复评中的 `macro F1` 均值为 `0.9398`。

## 当前结论

本轮达到了最初目标的一半：相比 `iteration_3`，repeated split 的 accuracy 和 F1(g) 明显恢复，几乎回到默认随机森林水平；相比 `iteration_2`，CV accuracy 和 CV F1(g) 更高。

但它没有保留 `iteration_3` 的复杂度优势。最终模型训练集 accuracy、F1 和 ROC-AUC 又回到 `1.0000`，说明 repeated split 复评更偏向选择拟合能力强的候选，而不是更保守的候选。

因此 `iteration_4` 可以作为随机森林当前分类指标最强的版本之一，但不能作为“控制过拟合”的最佳版本。若报告强调重复划分稳定性，可优先比较 `iteration_2` 和 `iteration_4`；若报告强调过拟合缓解，应保留 `iteration_3` 的解释价值。
