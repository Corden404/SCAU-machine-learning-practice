# 随机森林记录

## 1. 当前迭代概况

目前 RandomForest 已完成五次有效迭代。

1. `iteration_1` 使用默认参数随机森林，作为单次划分 baseline。
2. `iteration_2` 模型参数保持默认，增加 5 折交叉验证和多随机种子重复划分，用于观察集成模型稳定性。
3. `iteration_3` 使用 `RandomizedSearchCV` 大范围搜索随机森林主要超参数，观察复杂度控制和泛化指标变化。
4. `iteration_4` 围绕 `iteration_2` 和 `iteration_3` 做局部随机搜索，并对 CV 前列候选做 repeated split 复评。
5. `iteration_5` 以 `iteration_2` 和 `iteration_4` 的模型为基础，做分类阈值分析，确认默认阈值 0.5 是否最优。

这一轮说明默认随机森林在固定划分上表现很强，测试集 accuracy、F1(g)、macro F1 和 ROC-AUC 都比较高。相比默认单棵决策树，随机森林明显减少了单棵树划分不稳定带来的误差。

但训练集所有指标都是 `1.0000`，说明默认随机森林仍然可以把训练集完全拟合。它的泛化表现好，并不代表没有过拟合风险。

## 4. 前两次迭代说明什么

1. 随机森林相比单棵决策树有明显优势。默认随机森林的单次 accuracy 为 `0.9577`，明显高于默认决策树的 `0.9014`，也高于剪枝后决策树的 CV / repeated 水平。
2. 随机森林的稳定性较好。`iteration_2` 的重复划分 accuracy 均值为 `0.9465`，F1(g) 为 `0.9594`，ROC-AUC 为 `0.9803`，说明它比单棵树更不依赖某一次数据划分。
3. 当前主要问题不是欠拟合，而是训练集完全拟合。默认随机森林每棵树默认可以长得很深，集成后测试效果好，但过拟合迹象仍然明显。
4. `b` 类 recall 在单次划分上达到 `0.9600`，暂时不是主要短板。相比 AdaBoost，随机森林在少数类 `b` 上没有明显偏弱。
5. ROC-AUC 高于 accuracy / F1 的相对表现，说明模型排序能力强。后续 `iteration_5` 已验证阈值调整对随机森林的收益极低，默认阈值 0.5 已是最优。

## 5. iteration_3 大范围超参数搜索结果

本轮使用 `RandomizedSearchCV`，随机采样 `160` 组候选参数，每组做 5 折交叉验证，共约 `800` 次模型拟合。

搜索参数包括：

1. 树数量：`n_estimators`。
2. 分裂准则：`criterion`。
3. 树复杂度：`max_depth`、`min_samples_split`、`min_samples_leaf`、`max_leaf_nodes`、`min_impurity_decrease`、`ccp_alpha`。
4. 特征和样本采样：`max_features`、`bootstrap`、`max_samples`。
5. 类别权重：`class_weight`。

最优参数：

```text
n_estimators = 300
criterion = log_loss
max_depth = None
min_samples_split = 8
min_samples_leaf = 4
max_features = 0.3
bootstrap = True
max_samples = 1.0
max_leaf_nodes = 16
min_impurity_decrease = 0.0
ccp_alpha = 0.001
class_weight = None
```

网格搜索最佳 `macro F1` 为 `0.9397`。

测试集分类结果：

但是它不是全面优于默认参数：它在 5 折 CV 的 accuracy 和 F1(g) 上更好，单次 ROC-AUC 也更高；但在单次 accuracy、单次 F1(g)、`b` 类 recall 和重复划分均值上均低于默认参数。

因此 `iteration_3` 更适合作为“复杂度控制版本”，而不是直接替代默认随机森林成为唯一最佳版本。

## 6. iteration_4 局部搜索与 repeated 复评结果

本轮分两阶段：

1. 使用 `RandomizedSearchCV` 在局部参数空间随机采样 `220` 组候选，每组做 5 折 CV。
2. 取 CV 前 `24` 个候选，用 `0, 1, 2, 3, 4` 五个随机种子做 repeated split 复评，最终按 repeated `macro F1` 均值选择模型。

候选范围：

```text
n_estimators = [100, 200, 300]
criterion = ["gini", "entropy", "log_loss"]
max_features = ["sqrt", 0.3, 0.5]
max_leaf_nodes = [None, 16, 32]
min_samples_leaf = [1, 2, 4]
min_samples_split = [2, 4, 8]
ccp_alpha = [0.0, 0.001]
max_samples = [None, 0.8, 1.0]
bootstrap = True
class_weight = None
```

CV 阶段最优参数：

```text
n_estimators = 200

min_samples_split = 8
ccp_alpha = 0.001
```

## 7. 下一次迭代建议 → iteration_5 阈值分析

随机森林已经完成默认模型、大范围搜索、局部搜索和 repeated 复评。下一步不建议继续扩大搜索空间。

当前三个可用版本的取向不同：

1. `iteration_2` 默认随机森林：重复划分表现更好，但训练集完全拟合。
2. `iteration_3` 搜索后随机森林：训练集不再满分，CV accuracy / F1(g) 更好，但重复划分下降。
3. `iteration_4` 局部搜索后随机森林：CV 和 repeated 分类指标较好，但训练集再次满分。

按照上述分析，`iteration_5` 不再调整树结构，改为对 `iteration_2` 默认模型和 `iteration_4` 局部搜索模型做阈值分析。

### 7.1 方法

- 阈值范围：0.10 ~ 0.90，步长 0.02，共 41 个候选阈值
- 评估方式：5 个随机种子（0, 1, 2, 3, 4）重复划分，取均值
- 观察指标：macro F1、accuracy、F1(g)、F1(b)、recall(b)、recall(g)

### 7.4 阈值分析结论

1. **默认阈值 0.5 已经接近最优。** 两个模型在 0.44~0.52 范围内 macro F1、accuracy、F1(g) 几乎不变，随机森林的概率输出校准良好。
2. **b recall 的提升代价极大。** 提高阈值可将 b recall 推至 0.984（iter2）或 0.968（iter4），但 accuracy 从 ~0.946 跌至 ~0.82，macro F1 从 ~0.94 跌至 ~0.82。原因是高阈值下几乎将所有样本预测为 b 类，g recall 暴跌。
3. **阈值调整在随机森林上收益远低于预期。** ROC-AUC 虽高，但两个类别的概率分布在默认阈值附近重叠度不低，单纯调阈值无法在不损害整体指标的前提下改善某一类 recall。
4. **不建议继续调阈值。** iteration_2、iteration_3、iteration_4 已完成随机森林的全部有效探索，可直接进入最终模型对比阶段。

## 8. 后续可能方向

`iteration_5` 已完成阈值分析，结论是默认阈值 0.5 已最优，不建议在随机森林上继续迭代。

后续工作应进入模型对比阶段：

1. 如果最终报告强调泛化稳定性，优先用 repeated split 表现做模型排序，此时 `iteration_2` 和 `iteration_4` 都是强候选。
2. 如果强调过拟合控制，应保留 `iteration_3` 的解释价值。
3. 随机森林作为传统模型中的强 baseline，可与 AdaBoost、决策树等模型直接对比，进入最终模型选择。

## 9. 当前结论

随机森林是目前很有竞争力的传统模型之一。默认参数版本已经很强，尤其重复划分和 ROC-AUC 表现稳定；大范围搜索版本则提供了一个复杂度更低的替代方案。

当前不能简单说某一轮全面最好：

1. 如果看 repeated accuracy 和 F1(g)，`iteration_2` 与 `iteration_4` 都很强。
2. 如果看 CV accuracy 和 F1(g)，`iteration_4` 最好。
3. 如果看训练集不过度满分，`iteration_3` 最有解释价值。
4. 如果看 ROC-AUC，默认随机森林仍然非常有竞争力。

`iteration_5` 阈值分析表明：默认阈值 0.5 已经是最优选择，两个模型在 0.44~0.52 范围内指标几乎不变；提高阈值虽可换取 b recall 提升（最高 0.984），但 accuracy 和 macro F1 会从 ~0.94 跌至 ~0.82，不具备实用价值。阈值调整在随机森林上收益极低，不建议作为优化方向。

随机森林已不适合继续调参。后续应直接进入最终模型对比阶段，将 `iteration_2`、`iteration_3`、`iteration_4` 作为三个有不同解释价值的版本与其他模型横向比较。
