# 机器学习实验总览

## 1. 项目概述

本目录包含 Ionosphere（电离层雷达回波）二分类数据集的完整机器学习实验。目标是对比 5 种传统模型 + 模型集成在该数据集上的表现，并通过迭代优化找到最佳模型。

- **数据集**：Ionosphere，351 样本 × 34 特征，b:g = 126:225 (36%:64%)
- **任务**：二分类（b = bad 雷达回波 / g = good 雷达回波）
- **评估方式**：分层单次划分 + 5 折交叉验证 + 5 种子重复划分
- **统一指标**：accuracy、macro F1、F1(g)、F1(b)、recall(b)、recall(g)、ROC-AUC

## 2. 各模型迭代概况

### 2.1 RandomForest（6 次迭代）

| 迭代 | 内容 | 关键发现 |
| --- | --- | --- |
| iter1 | 默认参数 baseline | 训练集 1.0000，测试集 accuracy 0.9577 |
| iter2 | 默认 + CV + repeated split | repeated accuracy 0.9465，macro F1 0.9405 |
| iter3 | RandomizedSearchCV（160 组） | CV 提升但 repeated 下降，训练集不再满分 |
| iter4 | 局部搜索 + repeated 复评（220 组） | CV accuracy 0.9487，训练集再次满分 |
| iter5 | 阈值分析（0.10~0.90） | 默认阈值 0.5 已最优，调整无收益 |
| iter6 | class_weight 实验 | None 最优，balanced 轻微为负 |

**推荐版本**：iter2（泛化最稳定，repeated macro F1 0.9405）/ iter4（CV 最优）

### 2.2 SVM（8 次迭代）

| 迭代 | 内容 | 关键发现 |
| --- | --- | --- |
| iter1 | 默认参数 baseline | 未标准化，单次 accuracy 0.9014 |
| iter2 | + StandardScaler + CV | 标准化后显著提升 |
| iter3 | 搜索 C | C=3.0 最优 |
| iter4 | 搜索 gamma + class_weight | gamma=0.03, balanced 最优 |
| iter5 | 全核搜索（linear/rbf/poly） | **RBF 核最优**，CV macro F1 0.9563 |
| iter6 | 阈值调整 | 5 种子显示有提升 |
| iter7 | 30 种子扩大验证 | **推翻 iter6**，默认阈值 0.0 更优 |
| iter8 | RobustScaler + PCA | 无提升，预处理改进空间穷尽 |

**推荐版本**：iter5（RBF SVC, C=3.0, gamma=0.03, class_weight='balanced'），repeated macro F1 0.9463

### 2.3 LogisticRegression（5 次迭代）

| 迭代 | 内容 | 关键发现 |
| --- | --- | --- |
| iter1 | 默认参数 baseline | 线性模型，表现一般 |
| iter2 | + StandardScaler | 标准化小幅提升 |
| iter3 | + PolynomialFeatures(degree=2) | 二阶多项式是关键提升 |
| iter4 | L1/L2/ElasticNet GridSearchCV | **L2 + C=3.0 最优** |
| iter5 | interaction_only + ElasticNet 稀疏 + 系数分析 | 平方项不可缺，稀疏版仅需 100/594 特征达 0.9360 |

**推荐版本**：iter4（poly2 + L2 + C=3.0），repeated macro F1 0.9331。可解释性备选：ElasticNet 稀疏版（100 特征，macro F1 0.9360）

### 2.4 AdaBoost（6 次迭代）

| 迭代 | 内容 | 关键发现 |
| --- | --- | --- |
| iter1 | 默认参数 baseline | 单次 accuracy 0.9577 |
| iter2 | learning_rate=0.5 | 降低学习率，CV 和 repeated 有所提升 |
| iter3 | 默认 + CV + repeated | 补齐稳定性评估 |
| iter4 | GridSearchCV 全参数（n_estimators, lr, tree params） | 小幅提升，训练集满分 |
| iter5 | 阈值分析（0.10~0.90） | **阈值 0.48 提升 macro F1 0.9270→0.9327** |
| iter6 | class_weight 实验 | None 最优，balanced 显著为负 |

**推荐版本**：iter4 + th=0.48，repeated macro F1 0.9327

### 2.5 DecisionTree（5 次迭代）

| 迭代 | 内容 | 关键发现 |
| --- | --- | --- |
| iter1 | 默认参数 baseline | 严重过拟合，训练集 1.0000 |
| iter2 | 限制 max_depth | 过拟合减轻但泛化仍不足 |
| iter3 | ccp_alpha 剪枝 | CV 和多种子 accuracy 提升 |
| iter4 | max_depth + min_samples_leaf 搜索 | 小幅改进，但天花板已到 |
| iter5 | criterion 比较（gini/entropy/log_loss） | gini 最优，entropy 同 ccp_alpha 下更易过拟合 |

**推荐版本**：iter4（ccp_alpha=0.00852, max_depth=8），repeated macro F1 0.8705。主要价值在可解释性而非精度。

## 4. 模型集成

基于最佳单模型的集成实验（详见 [Ensemble/](Ensemble/)）：

| 排名 | 方法 | accuracy | macro F1 | vs SVM(Δ) |
| --- | --- | ---: | ---: | ---: |
| 1 | **Stacking (SVM+RF+LR→LR)** | 0.9634 | **0.9591** | **+0.0128** |
| 2 | Voting-Soft (top3) | 0.9521 | 0.9461 | -0.0002 |
| 3 | Stacking (5 models) | 0.9521 | 0.9461 | -0.0002 |
| 4 | Voting-Hard (5 models) | 0.9437 | 0.9368 | -0.0094 |
| 5 | Voting-Soft (5 models) | 0.9408 | 0.9333 | -0.0130 |

**关键发现**：
- **Stacking (SVM + RF + LR → LogisticRegression) 是项目最佳模型**，macro F1 0.9591，比最佳单模型 SVM 高 1.28 个百分点
- Top3 集成优于全 5 模型——AdaBoost 和 DT 稀释了集成效果
- Voting 不如 Stacking——简单投票无法充分利用基模型互补性

## 5. 数据处理改进尝试

| 实验 | 模型 | 结果 |
| --- | --- | --- |
| RobustScaler 替代 StandardScaler | SVM iter8 | **无提升**（差异 <±0.003），SVM RBF 核对离群值鲁棒 |
| PCA 降维（90%/95%/99% 方差） | SVM iter8 | **明确有害**（-0.006），34 特征信号分布均匀 |
| class_weight='balanced' | RF iter6 | **轻微为负**（-0.007），bootstrap 已提供类别多样性 |
| class_weight='balanced' | AdaBoost iter6 | **明确为负**（-0.024），双重加权导致过拟合 |
| 阈值调整 | RF iter5 | **无收益**，默认 0.5 最优 |
| 阈值调整 | AdaBoost iter5 | **有收益**（+0.006），阈值 0.5→0.48 |
| 阈值调整 | SVM iter6→7 | **5 种子结论被 30 种子推翻**，默认阈值更优 |

**结论：数据预处理改进空间已基本穷尽。** 当前 StandardScaler（SVM/LR）+ 原始特征（RF/AdaBoost/DT）的方案已经足够。

## 6. 关键结论

1. **SVM（RBF + balanced）是最佳单模型。** 在 repeated split 和 CV 上双料第一，且经过 30 种子验证。

2. **集成超越单模型。** Stacking (SVM+RF+LR→LR) macro F1 达 0.9591，比 SVM 高 1.28 个百分点。三个互补性最强的模型组合效果最好。

3. **默认 RF 是极强 baseline。** 无需任何调参即排第 2，且标准差最小（最稳定），体现了集成学习的优势。

4. **多项式特征对 LR 至关重要。** 去平方项后 CV macro F1 从 0.9396 跌至 0.9002，证明 Ionosphere 数据需要非线性边界。

5. **阈值调整只在 AdaBoost 上有收益。** RF 和 SVM 的默认阈值已最优，AdaBoost 概率校准略逊。

6. **class_weight 在这个数据集上普遍不适用。** 36:64 的不平衡程度不足以触发正向效果，RF 的 bootstrap 和 AdaBoost 的样本权重机制已提供足够处理。

7. **PCA 降维对 SVM 有害。** 34 个特征信号分布均匀，无冗余维度可减。

8. **单棵决策树天花板很低。** 差距约 7-8 个百分点，价值在可解释性而非精度。
