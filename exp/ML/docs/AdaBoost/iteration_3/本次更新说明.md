# 本次更新说明

## 迭代定位

本轮是 AdaBoost 的第 3 次迭代，用于补齐默认参数模型的稳定性评估。

## 相比上次的变化

1. 相比 `iteration_2`，取消 `learning_rate=0.5`，恢复默认 AdaBoost 参数。
2. 保留 5 折交叉验证和多随机种子重复划分，用同一评估口径比较默认参数和小学习率方案。
3. 本轮不引入新的超参数搜索，重点判断 `iteration_1` 的单次高分是否具有稳定性。

## 本轮结果

单次划分与 `iteration_1` 完全一致：

| 指标 | 测试集 |
| --- | ---: |
| accuracy | 0.9577 |
| F1(g) | 0.9684 |
| ROC-AUC | 0.9791 |

新增稳定性评估：

| 评估方式 | accuracy | F1(g) | ROC-AUC |
| --- | ---: | ---: | ---: |
| 5 折 CV 均值 | 0.9401 | 0.9545 | 0.9608 |
| 5 折 CV 标准差 | 0.0468 | 0.0358 | 0.0282 |
| 重复划分均值 | 0.9296 | 0.9473 | 0.9631 |
| 重复划分标准差 | 0.0263 | 0.0201 | 0.0221 |

## 与上次对比

相比 `iteration_2` 的 `learning_rate=0.5`，默认参数在 5 折 CV 上的 accuracy 和 F1(g) 更高：

| 指标 | iteration_2 | iteration_3 |
| --- | ---: | ---: |
| CV accuracy | 0.9259 | 0.9401 |
| CV F1(g) | 0.9443 | 0.9545 |
| CV ROC-AUC | 0.9589 | 0.9608 |
| repeated accuracy | 0.9239 | 0.9296 |
| repeated F1(g) | 0.9437 | 0.9473 |
| repeated ROC-AUC | 0.9557 | 0.9631 |

## 当前结论

默认 AdaBoost 的高分不是单次划分偶然结果，它在 CV 和重复划分上也优于 `learning_rate=0.5`。但默认参数训练集指标接近满分，仍然有过拟合倾向；后续应以默认参数为基础，优先搜索 `n_estimators`，观察减少或增加迭代轮数是否能进一步平衡泛化效果和过拟合风险。
