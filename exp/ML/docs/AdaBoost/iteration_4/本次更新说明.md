# 本次更新说明

## 迭代定位

本轮是 AdaBoost 的第 4 次迭代，用于一次性搜索主要超参数组合。

## 相比上次的变化

1. 相比 `iteration_3`，从默认参数扩展为全主要超参数维度的粗网格搜索。
2. 同时搜索 AdaBoost 自身的 `n_estimators`、`learning_rate`。
3. 同时搜索弱学习器决策树的 `max_depth`、`min_samples_leaf`、`criterion`、`class_weight`。
4. 使用 5 折交叉验证的 `macro F1` 作为主选择指标，并同时观察 `b` 类 recall、`g` 类 F1、accuracy、ROC-AUC。
5. 本轮候选组合共 `576` 组，属于探索型迭代，即使结果变差也保留，用于说明大范围调参是否真正有收益。

## 搜索设置

候选范围：

| 参数 | 候选值 |
| --- | --- |
| `n_estimators` | `25, 50, 100, 200` |
| `learning_rate` | `0.1, 0.5, 1.0, 1.5` |
| `estimator__max_depth` | `1, 2, 3` |
| `estimator__min_samples_leaf` | `1, 2, 5` |
| `estimator__criterion` | `gini, entropy` |
| `estimator__class_weight` | `None, balanced` |

`algorithm` 没有搜索，因为当前 sklearn 版本中该参数已废弃。

## 最优参数

以 5 折 CV 的 `macro F1` 作为主选择指标，最优组合为：

```text
estimator__class_weight = None
estimator__criterion = entropy
estimator__max_depth = 2
estimator__min_samples_leaf = 2
learning_rate = 0.5
n_estimators = 50
```

网格搜索中的最佳 `macro F1` 为 `0.9399`。

## 当前结论

全参数维度搜索带来了小幅收益，尤其 CV accuracy、CV F1(g)、重复划分 accuracy 和重复划分 F1(g) 都高于默认参数。单次测试集 accuracy 持平，`b` 类 recall 从 `0.8800` 提升到 `0.9200`，说明浅树基学习器有助于减少少数类 `b` 被误判为 `g`。

但本轮训练集 accuracy、F1 和 ROC-AUC 都达到 `1.0000`，过拟合迹象比 `iteration_3` 更强。当前如果按 CV / repeated 的分类指标选择，`iteration_4` 是 AdaBoost 的最好版本；如果更看重单次 ROC-AUC 或模型保守性，`iteration_3` 仍有参考价值。
