# 本次更新说明

## 迭代定位

本轮是 AdaBoost 的第 6 次迭代，补充验证基学习器 class_weight 的效果。

## 背景

iteration_4 的 GridSearchCV 已将 `estimator__class_weight` 纳入搜索空间（值 `[None, "balanced"]`），搜索结果是 `None` 更优（以 macro_f1 为选择指标）。但 GridSearchCV 只跑了一次 CV 划分，本次实验做了更详细的多次划分验证。

## 方法

- 固定 iteration_4 最优参数（n_estimators=50, learning_rate=0.5, estimator__max_depth=2, estimator__min_samples_leaf=2, estimator__criterion=entropy）
- 对比 `estimator__class_weight=None` vs `balanced`
- 单次划分 + 5 折 CV + 5 次随机划分

## 结果

### 多次随机划分（5 seeds, mean ± std）

| Metric | None | balanced |
|---|---|---|
| test_accuracy | **0.9352** ±0.0161 | 0.9042 ±0.0336 |
| test_f1 | **0.9515** ±0.0115 | 0.9273 ±0.0268 |
| test_recall(g) | **0.9783** ±0.0000 | 0.9478 ±0.0451 |
| test_roc_auc | **0.9621** ±0.0137 | 0.9392 ±0.0291 |

### 5 折交叉验证

| Metric | None | balanced |
|---|---|---|
| test_accuracy | **0.9458** ±0.0158 | 0.9173 ±0.0327 |
| test_f1 | **0.9588** ±0.0120 | 0.9384 ±0.0236 |

### 单次划分（seed=42）

两者完全一致（accuracy=0.9577, f1=0.9677, recall=0.9783），仅 ROC-AUC 有差异：None=0.9652, balanced=0.9857。

## 结论

1. **class_weight='balanced' 对 AdaBoost 效果明确为负。** 全部指标下降，test_f1 从 0.9515 降至 0.9273，accuracy 从 0.9352 降至 0.9042。
2. **稳定性显著恶化。** accuracy 标准差从 0.0161 翻倍至 0.0336，recall(g) 标准差从 0 飙升至 0.0451。
3. 原因：AdaBoost 本身通过调整样本权重处理难分样本，额外加 class_weight 造成双重加权，过度关注 b 类。
4. **验证了 iteration_4 GridSearchCV 的结论（选择 class_weight=None），推荐保持 None。**
