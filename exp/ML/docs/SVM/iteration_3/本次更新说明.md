# 本次更新说明

## 迭代定位

本轮是在 `iteration_2` 的基础上做第一步贪心改进：只调整 RBF SVM 的 `C`，不同时调整 `gamma`、核函数或类别权重。

## 相比上次的变化

1. 保留 `StandardScaler + RBF SVC`，延续 iteration_2 中对 SVM 更规范的标准化流程。
2. 将默认 `C=1.0` 改为候选集搜索：`0.1`, `0.3`, `1.0`, `3.0`, `10.0`, `30.0`。
3. 固定 `gamma='scale'`，因为本轮只验证 `C` 这一项改动是否有效。
4. 使用 5 折交叉验证的 macro F1 选择最佳 `C`，同时输出 accuracy、`b` 类 F1、`b` 类 recall 和 ROC-AUC 作为辅助判断。

## 判断标准

如果最佳 `C` 相比默认值带来更好的交叉验证或多随机种子表现，并且 `b` 类 recall 没有明显下降，则接受本轮改动；否则回退到 iteration_2 的默认 `C=1.0`。

## 运行结果

本轮最佳参数为 `C=3.0`，固定 `kernel='rbf'`、`gamma='scale'`。

1. 单次测试集 accuracy 为 0.9577，F1 为 0.9677，与 iteration_2 一致。
2. 单次测试集 ROC-AUC 从 0.9713 提高到 0.9748。
3. 5 折 CV accuracy 从 0.9401 提高到 0.9515，F1 从 0.9548 提高到 0.9629。
4. 多随机种子 accuracy 从 0.9465 提高到 0.9549，F1 从 0.9602 提高到 0.9663。
5. 单次测试集 `b` 类 recall 保持 0.9200，没有下降。

## 结论

`C=3.0` 是有效改进，接受为新的 SVM baseline。下一轮如果继续迭代，应在 `C=3.0` 基础上只调 `gamma`，不要直接做大网格搜索。
