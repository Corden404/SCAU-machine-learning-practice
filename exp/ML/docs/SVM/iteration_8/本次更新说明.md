# 本次更新说明

## 迭代定位

本轮根据数据预分析结果（IQR 离群值占比 47%、特征/样本比 1:8），测试两种预处理改进：

- **RobustScaler** 替代 StandardScaler（中位数/IQR 替代均值/标准差，对离群值更鲁棒）
- **PCA 降维** 保留 90%/95%/99% 方差，减少 RBF 核在高维空间的噪声

SVC 参数沿用 iteration_5 最优配置（C=3.0, gamma=0.03, class_weight='balanced'），GridSearchCV 选择最佳预处理方案。

## 结果

GridSearchCV（36 组候选）：

| 预处理方案 | CV macro F1 | 最佳 C | 最佳 gamma |
| --- | ---: | ---: | ---: |
| RobustScaler only | **0.9530** | 3.0 | 0.03 |
| RobustScaler + PCA(0.99) | 0.9500 | 3.0 | 0.03 |
| RobustScaler + PCA(0.95) | ~0.948 | — | — |
| RobustScaler + PCA(0.90) | ~0.942 | — | — |

RobustScaler only 胜出，说明 PCA 降维对 SVM 有害。

### 与 iteration_5 (StandardScaler) 对比

| 指标 | iter_5 StandardScaler | iter_8 RobustScaler | Δ |
| --- | ---: | ---: | ---: |
| CV accuracy | 0.9600 | 0.9573 | -0.0027 |
| CV F1(g) | 0.9690 | 0.9672 | -0.0018 |
| CV ROC-AUC | 0.9822 | 0.9839 | +0.0017 |
| Repeated accuracy | 0.9521 | 0.9549 | +0.0028 |
| Repeated F1(g) | 0.9639 | 0.9663 | +0.0024 |
| Repeated ROC-AUC | 0.9873 | 0.9861 | -0.0012 |

## 结论

1. **RobustScaler 未带来实质提升。** 所有指标差异在 ±0.003 内，属于噪声范围。SVM RBF 核对离群值有足够鲁棒性。
2. **PCA 降维对 SVM 有害。** CV macro F1 从 0.9530 降至 0.9500（PCA 0.99），方差保留越多损失越小。34 个特征的有效信号分布均匀，任何降维都会丢失信息。
3. **StandardScaler 仍然是 SVM 的最佳选择。** iter_5 保持为最佳单模型版本。
4. **数据预处理改进空间已基本穷尽。** 建议不再继续预处理方向的迭代。
