# 本次更新说明

## 迭代定位

本轮是 LogisticRegression 的第 4 次迭代，用于测试二阶多项式升维和不同正则化形式是否能提升模型表现。

## 相比上次的变化

1. 不继续沿用 iteration_3 的 `class_weight='balanced'`，因为上一轮没有带来稳定提升。
2. 保留 `VarianceThreshold`，继续去除常量特征。
3. 加入 `PolynomialFeatures(degree=2, include_bias=False)`，构造二阶多项式特征和交互特征。
4. 在多项式升维后加入 `StandardScaler`，避免新增特征尺度差异影响正则化。
5. 使用 `LogisticRegression(solver='saga')`，同时支持 L1、L2 和 Elastic Net。
6. 对正则化形式和强度做网格搜索：L1、L2、Elastic Net 均重新搜索 `C`，Elastic Net 额外搜索 `l1_ratio`。
7. 使用 5 折交叉验证按 macro F1 选择最佳参数，再输出单次划分、交叉验证和多随机种子评估结果。
