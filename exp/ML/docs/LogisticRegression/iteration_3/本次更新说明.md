1. 保留 iteration_2 中的 `VarianceThreshold`，继续去除常量特征。
2. 保留 iteration_2 中的 `StandardScaler`，继续在标准化特征上训练逻辑回归。
3. 加入 `class_weight='balanced'`，尝试缓解 `b=126`、`g=225` 带来的类别比例差异。

6. 继续输出单次划分、5 折交叉验证和多随机种子分层划分结果，用于判断改进是否稳定。
