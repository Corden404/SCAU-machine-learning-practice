# 模型集成对比报告

## 集成方法

- **Voting-Hard**: 5 个基模型多数投票
- **Voting-Soft**: 5 个基模型预测概率取平均后 argmax
- **Voting-Soft-Top3**: 仅用 SVM + RF + LR 三个最强模型做软投票
- **Stacking**: 5 个基模型输出作为特征，LogisticRegression 元模型（5 折 CV 内训）
- **Stacking-Top3**: 仅用 SVM + RF + LR 三个最强模型做 Stacking

基模型：SVM iter5、RF iter2、LR iter4、AdaBoost iter4 (th=0.48)、DT iter4

## 分析

### 最佳集成：Stacking (top3)

Stacking (SVM + RF + LR → LogisticRegression) 在 repeated split 上全面超越最佳单模型 SVM：

| 指标 | SVM iter5 | Stacking (top3) | Δ |
| --- | ---: | ---: | ---: |
| accuracy | 0.9521 | 0.9634 | +0.0113 |
| macro F1 | 0.9463 | 0.9591 | +0.0128 |
| F1(g) | 0.9639 | 0.9723 | +0.0084 |
| F1(b) | 0.9287 | 0.9459 | +0.0172 |
| recall(b) | 0.8960 | 0.9200 | +0.0240 |
| recall(g) | 0.9826 | 0.9870 | +0.0043 |
| ROC-AUC | 0.9873 | 0.9882 | +0.0009 |

### 关键发现

1. **Stacking (top3) 是本实验最佳模型。** macro F1 0.9591，accuracy 0.9634，均显著超越 SVM（+0.0128 / +0.0113）。
2. **Top3（SVM+RF+LR）优于全 5 模型集成。** 加入 AdaBoost 和 DT 反而稀释了集成效果。SVM/RF/LR 三者互补性最强：非线性核、树集成、线性多项式。
3. **少数类 b 也受益。** b recall 从 0.8960 提升到 0.9200（+0.024），F1(b) 从 0.9287 提升到 0.9459（+0.0172）。
4. **Voting 不如 Stacking。** Voting-Hard/Soft 均未超越 SVM，说明简单投票无法充分利用基模型互补性，需要元模型学习加权。
5. **5 折 CV 上 SVM 仍略领先 Stacking。** CV macro F1：SVM 0.9563 vs Stacking 0.9531。Stacking 在 repeated split 上的优势部分来自固定划分，但在相同种子下确实更优。
6. **Hard Voting 无 ROC-AUC。** Hard voting 不输出概率，因此无法计算 ROC-AUC。

### 推荐

**最终推荐 Stacking (SVM + RF iter2 + LR iter4 → LogisticRegression) 为项目最佳模型。**
在报告中也应保留 SVM iter5 作为最佳单模型 baseline，展示集成的增量价值。
